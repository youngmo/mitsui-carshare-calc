# 三井のカーシェアーズ 料金シミュレーター（非公式）

開始時刻・利用時間・車種（71車種）・走行距離をすべてスライダーで調整しながら、三井のカーシェアーズ 個人ベーシックプランの料金をリアルタイムに試算する非公式シミュレーターです。**2026年4月1日改定料金**に対応。外部依存なしの単一HTMLファイルで、GitHub Pages・Netlify・ローカル実行いずれも対応します。

## 主な機能

- **オールスライダーUI**：日付以外のすべての入力をスライダーで操作
  - 開始時刻：0:00～23:50（10分刻み、144段階）
  - 利用時間：10分～168時間（10分刻み、1008段階）
  - 車種：71車種を一連のスライダーで（料金クラス順）
  - 走行距離：0～1000km（5km刻み、200段階）
- 開始日に**予約可能期間の制約**を適用（個人ベーシックプラン：予約終了日27日後まで）
- 利用時間が長すぎて終了が予約上限を超える場合は警告表示
- 最大8日間（192時間）のタイムライン上に予約区間と夜間パック帯（18時～翌9時）を可視化
- 動的計画法（DP）で `10分単価 / 6h / 12h / 24h パック` の最安組み合わせを自動探索
- ダークモード対応・モバイルレスポンシブ

## 車種ラインアップ（71車種）

2026年5月時点で公式サイトに掲載されている全車種を、料金クラス順に並べてスライダー化しています：

| クラス | 件数 | 10分単価 | 距離料金 |
|--------|------|---------|----------|
| ベーシック (BSC) | 25 | 150円 | 21円/km |
| ミドル (MID) | 15 | 190円 | 21円/km |
| ミドルプラス (MID+) | 15 | 220円 | 21円/km |
| プレミアム (PRM) | 7 | 290円 | 23円/km |
| プレミアムプラス (PRM+) | 9 | 520円 | 25円/km |
| **合計** | **71** | | |

スライダー下部に各クラスの占有比に応じた色帯セグメントを表示しているため、現在のスライダー位置がどのクラスに属するか視覚的に確認できます。

## 計算ロジック

### 基本ルール

- **予約 6時間以内**: `利用時間 × 10分単価` ・ `6hパック` ・ `夜間パック（該当時のみ）` の最安値を適用。距離料金は0円。
- **予約 6時間超**: 動的計画法で `10分単価 / 6h / 12h / 24h パック` の最適組み合わせを自動探索。距離料金（クラス別21～25円/km）が加算。
- 夜間パック（18時～翌9時、最大15時間）は ベーシック／ミドル／ミドルプラス のみ。
- 分は10分単位に切り上げ。

### DPの定式化

公式ルール：「予約時間に合わせて、10分単位の料金とパック料金から、常に最も安い組み合わせを適用します。なお、パック適用時間を越えた分については、別途その時間分の時間料金、またはパック料金が適用されます。」

これは「**t単位以上をカバーする最小コスト**」問題であり、「ちょうどt単位を埋める最小コスト」ではありません。例えば 47時間50分の予約は、24時間パック × 2 (= 48時間カバー、¥17,000) で48時間分を予約しているのと同等の料金になります。本シミュレーターのDP点火式：

```
dp[t] = min over options o: dp[max(0, t - o.units)] + o.cost
```

`max(0, t - o.units)` により、パックが予約時間を超過してカバーする組み合わせも候補に含まれます。

## 予約可能期間の制約

公式ルール（個人ベーシックプラン）：「ご予約終了日の27日前から予約が可能」。すなわち今日から数えて 27日後の23:50 までに**終了**する予約のみが取得可能です。

| 項目 | 設定値 |
|------|--------|
| 開始日 (`<input type="date">`) | min = 今日, max = 今日 + 27日 |
| 利用時間スライダー | 制約なし（最大168時間） |
| 違反時の挙動 | 終了時刻が上限を超える場合、警告メッセージを表示（強制ブロックはしない） |

これは、ユーザーが料金構造を試算する目的で長期予約のシナリオも検証できるよう、ソフトな制約としています。

## 反映していない項目（非公式ゆえの精度限界）

1. 昼夜にまたがる長時間予約での、夜間パックの**部分適用**による組み合わせ最適化
2. 延長・超過料金（通常料金の2倍）
3. 月会費880円および同額割引、学割、年間契約割引、キャンペーンクーポン
4. 輸入車のGPSベース距離料金算出
5. 月会費無料プラン（予約可能期間が30日のため別途設定要）

正確な請求額は[公式シミュレーション](https://www.carshares.jp/plan/simulation/)または会員ページでご確認ください。

## GitHub Pages へのデプロイ手順

### 1. リポジトリ作成
GitHub で新しい public リポジトリを作成（例：`mitsui-carshare-calc`）。

### 2. ファイルアップロード
`index.html` をリポジトリのルートに配置します。CLI を使う場合：

```bash
git clone https://github.com/<ユーザー名>/<リポジトリ名>.git
cd <リポジトリ名>
git add index.html README.md
git commit -m "Add carshare price simulator"
git push origin main
```

### 3. GitHub Pages 有効化
- **Settings** → 左メニュー **Pages**
- **Source** を `Deploy from a branch` に設定
- **Branch** を `main`（または `master`）／`/ (root)` に設定して **Save**

### 4. アクセス
1～2分後、以下のURLでアクセス可能：

```
https://<ユーザー名>.github.io/<リポジトリ名>/
```

## ローカル実行

`index.html` をダブルクリックするとブラウザで直接開きます。サーバーやビルドツールは不要です。

## キーボード操作

各スライダーにフォーカスした状態で：
- ←/→ または ↑/↓：1段階ずつ移動
- Home/End：最小値・最大値へジャンプ
- PageUp/PageDown：大きめのステップで移動

車種スライダーの場合、左右キーで1台ずつ切り替えられます。

## カスタマイズ

- **料金の変更**: `<script>` 内の `PRICING` オブジェクトでクラス別単価・パック価格を編集。
- **車種の追加・削除**: `MODELS` 配列を編集し、HTML の `<input id="carClass">` の `max` 属性（現在 `70` = 71車種の0インデックス）と `.class-segments` 内の各 `flex` 値を更新。
- **走行距離の最大値**: `<input id="distance">` の `max` 属性を変更。
- **予約可能日数**: `RESERVATION_LIMIT_DAYS` 定数（既定27日）を変更。
- **タイムライン表示時間**: `TIMELINE_HOURS` 定数（既定192時間）を変更。
