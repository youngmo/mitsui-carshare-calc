# 三井のカーシェアーズ 料金シミュレーター（非公式）

開始時刻・利用時間・車種・走行距離をすべてスライダーで調整しながら、三井のカーシェアーズ 個人ベーシックプランの料金をリアルタイムに試算する非公式シミュレーターです。**2026年4月1日改定料金**に対応。外部依存なしの単一HTMLファイルで、GitHub Pages・Netlify・ローカル実行いずれも対応します。

## 主な機能

- **オールスライダーUI**：日付以外のすべての入力をスライダーで操作
  - 開始時刻：0:00～23:50（10分刻み、144段階）
  - 利用時間：10分～72時間（10分刻み、432段階）
  - 車種クラス：5段階（BSC / MID / MID+ / PRM / PRM+）
  - 走行距離：0～1000km（5km刻み、200段階）
- 72時間タイムライン上に予約区間と夜間パック帯（18時～翌9時）を可視化
- 動的計画法（DP）で `10分単価 / 6h / 12h / 24h パック` の最安組み合わせを自動探索
- ダークモード対応・モバイルレスポンシブ

## 計算ロジック

### 基本ルール

- **予約 6時間以内**: `利用時間 × 10分単価` ・ `6hパック` ・ `夜間パック（該当時のみ）` の最安値を適用。距離料金は0円。
- **予約 6時間超**: 動的計画法で `10分単価 / 6h / 12h / 24h パック` の最適組み合わせを自動探索。距離料金（クラス別21～25円/km）が加算。
- 夜間パック（18時～翌9時、最大15時間）は ベーシック／ミドル／ミドルプラス のみ。
- 分は10分単位に切り上げ。

### DPの定式化

公式ルール：「予約時間に合わせて、10分単位の料金とパック料金から、常に最も安い組み合わせを適用します。なお、パック適用時間を越えた分については、別途その時間分の時間料金、またはパック料金が適用されます。」

これは「**t単位以上をカバーする最小コスト**」問題であり、「ちょうどt単位を埋める最小コスト」ではありません。例えば 47時間50分の予約は、24時間パック × 2 (= 48時間カバー、¥17,000) で48時間分を予約しているのと同等の料金になります。本シミュレーターのDP点火式：

```
dp[t] = min over options o: dp[max(0, t - o.units)] + o.cost
```

`max(0, t - o.units)` により、パックが予約時間を超過してカバーする組み合わせも候補に含まれます。

## 反映していない項目（非公式ゆえの精度限界）

1. 昼夜にまたがる長時間予約での、夜間パックの**部分適用**による組み合わせ最適化
2. 延長・超過料金（通常料金の2倍）
3. 月会費880円および同額割引、学割、年間契約割引、キャンペーンクーポン
4. 輸入車のGPSベース距離料金算出

正確な請求額は[公式シミュレーション](https://www.carshares.jp/plan/simulation/)または会員ページでご確認ください。

## GitHub Pages へのデプロイ手順

### 1. リポジトリ作成
GitHub で新しい public リポジトリを作成（例：`mitsui-carshare-calc`）。

### 2. ファイルアップロード
`index.html` をリポジトリのルートに配置します。Web UI のドラッグ＆ドロップが最も簡単です。CLI を使う場合：

```bash
git clone https://github.com/<ユーザー名>/<リポジトリ名>.git
cd <リポジトリ名>
git add index.html README.md
git commit -m "Add carshare price simulator"
git push origin main
```

### 3. GitHub Pages 有効化
リポジトリのページで：
- **Settings** → 左メニュー **Pages**
- **Source** を `Deploy from a branch` に設定
- **Branch** を `main`（または `master`）／`/ (root)` に設定して **Save**

### 4. アクセス
1～2分後、以下のURLでアクセス可能になります：

```
https://<ユーザー名>.github.io/<リポジトリ名>/
```

正確なURLは Settings → Pages の上部に表示されます。

## ローカル実行

`index.html` をダブルクリックするとブラウザで直接開きます。サーバーやビルドツールは不要です。

## キーボード操作

各スライダーにフォーカスした状態で：
- ←/→：1段階ずつ移動
- ↑/↓：1段階ずつ移動
- Home/End：最小値・最大値へジャンプ
- PageUp/PageDown：大きめのステップで移動

## カスタマイズ

- **料金の変更**: `<script>` 内の `PRICING` オブジェクトでクラス別単価・パック価格を編集。
- **車種クラスの追加**: `PRICING` にエントリを追加し、`CLASS_ORDER` 配列の対応位置に key を追加し、HTML の class slider の `max` 属性とマーカー（`.class-marks`）も更新。
- **走行距離の最大値**: `<input id="distance">` の `max` 属性を変更。
- **タイムライン表示時間**: `TIMELINE_HOURS` 定数（既定72時間）を変更。
